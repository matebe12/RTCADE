# 넷플레이 수동 QA

`docs/netplay-manual-qa.md`의 8개 테스트 섹션을 순서대로 진행하는 대화형 QA 가이드다.

## 전제 조건

1. `npm run dev:all` 실행 (Vite :5173 + Express :3001)
2. ROM 파일이 `server/roms/`에 준비되어 있는지 확인
3. 브라우저 2~3개 탭을 열 수 있는 환경

## QA 섹션 (순서대로 진행)

각 섹션마다:
1. 테스트 시나리오 설명을 보여준다
2. 필요한 브라우저 탭과 URL 해시를 안내한다 (예: `/#netplay`, `/ggpo-test#host`)
3. 기대 동작을 명시한다
4. 개발자에게 pass/fail을 확인한다
5. 실패 시 상세 내용을 기록한다

### 섹션 목록

1. **즐겨찾기/최근 플레이** — 최근 플레이 목록 표시, 즐겨찾기 추가/제거
2. **세션 종료 요약** — 게임 종료 후 플레이 시간, 결과 표시
3. **공개 방 목록** — 공개 방 브라우징, 필터링, 정렬
4. **비공개 방 검증** — 코드로만 입장 가능한지, 목록에 노출되지 않는지
5. **최근 상대 / 빠른 참가** — 이전 상대 표시, 빠른 재접속
6. **대기실 / 준비 / 관전자** — 준비 상태 토글, 관전자 입장, 역할 고정
7. **관전자 연결 / 첫 프레임** — 관전자 화면 표시, 첫 프레임 렌더링
8. **인기 게임 플레이 시간** — 인기 게임 목록, 플레이 시간 집계 표시

## 결과 요약

```
넷플레이 QA 결과:
✅ 1. 즐겨찾기/최근 플레이
✅ 2. 세션 종료 요약
❌ 3. 공개 방 목록 — 방 목록이 빈 배열로 표시됨
...
통과: 7/8
```

## 참고

- `docs/netplay-manual-qa.md`가 최신인지 먼저 확인한다
- GGPO 테스트 페이지(`/ggpo-test`)는 별도 QA가 필요하면 추가 섹션으로 진행한다
